# Nail Vitals

An iPhone app that screens for nail signs from phone photos. A screening aid, not a diagnosis.

- App and tools: [nail-vitals-ios/](nail-vitals-ios/README.md)
- Assistant proxy (Cloudflare Worker): `server/gemini-proxy/`
- v2 design spec and build plans: `docs/superpowers/`
- `captures/` and `testset/` hold photos and are never committed.
